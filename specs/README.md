# Specs

This repository uses versioned specs under `specs/`.

- `specs/v0.1.0.md` is the active spec and the scope boundary for the first
  release. Tracked work in `planning/tasks/` links to its headings.
- `specs/v0.2.0.md` is an inactive draft holding work deferred from v0.1.0.
- `specs/v0.3.0.md` is an inactive draft for comparing trunk-based integration
  with longer-lived pull-request branches and for modeling non-blocking
  continuous review.

## Reading Order

1. `specs/v0.1.0.md`
2. `specs/v0.2.0.md`
3. `specs/v0.3.0.md`
